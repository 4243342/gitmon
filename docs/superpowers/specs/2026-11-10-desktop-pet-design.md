# 桌宠组件（页面内 DesktopPet）设计

状态：已定稿（用户已批准设计，批准后直接进入实现）。

## 1. 目标与形态

在 GitMon 页面内加一个常驻桌宠：**A 档「站桩 + 待机动画」**。

- 新组件 `src/components/DesktopPet.jsx`，`position: fixed` 停靠视口**右下角**。
- 挂载在 App 根部，**全视图常驻**（不随 view 切换卸载），`z-index` 高于普通内容、低于全屏弹窗/演出层。
- 待机动画（纯 CSS，立绘是单帧静态 PNG，无序列帧）：
  - 呼吸浮动（复用/对齐现有 `sprite-float` 节奏）；
  - 随机间隔冒气泡：从该宠 `description` / `traits` 里抽一句，或「在看你的仓库…」类闲聊文案（走 i18n `t()`）；
  - 点击 → 轻跳一下（scale 弹跳）+ 冒气泡。
- 右上角小 `✕` 收起；收起后缩为角落一枚小球，点小球还原。
- 参考：行为与气泡交互手感参考 **dsh-pet（MIT）** 的 overlay 思路；**不引入其插件体系，零新 npm 依赖**。

## 2. 选择器（精灵仓库 hero 标题行）

> 修订（用户反馈）：原「Collection 页头行」太简陋——选择框改挪到精灵仓库 hero 标题行（`hero-title-row`，标题右侧），并给桌宠本体加**拖动**（位置记忆）。

- 精灵仓库 hero 标题行右侧「**桌宠上任**」选择器（**卡片可视化**，修订 v2）：
  - 当前桌宠徽章（小立绘 + 名字 + Lv + ▾），点开弹出横向迷你卡条（品质角标 + 立绘 + 名字 + Lv），**点哪张哪张上任**（选中卡带品质色/高亮描边），点外部或 Esc 收起；
  - 同处 ON/OFF 开关（`set-toggle`）。
- 未选择过时的默认：图鉴第一只；图鉴为空则桌宠不渲染。
- 桌宠可**按住拖动**到视口任意位置（≥6px 死区防误触；拖完写回 localStorage `pos`，载入时夹回视口内；拖动与点击互动互斥）。

## 3. 数据与存储（遵循 docs/SSOT.md）

- 宠物数据**直接读本地图鉴镜像** `localStorage['gitmon:collection:v2']`（UI 永远先读本地、不等网络），**不新增后端接口**。
- 立绘复用现有 sprite 解析（含自定义形象优先），`image-rendering: pixelated`。
- 桌宠选择 + 开关 + 收起状态 + 拖动位置（`pos`）存 `localStorage['gitmon:deskpet']` —— 按 SSOT §1 属**轻 UI 状态**，与静音/编队同级，**不上云、不入脏队列**。

## 4. 边界与错误处理

- 图鉴为空 → 组件不渲染（静默）。
- 所选宠被删除 → 回退图鉴第一只并静默改存；图鉴整体被清空 → 不渲染。
- 收起状态、开关、所选宠均以 localStorage 为准，读取失败（隐私模式）时降级为本次会话默认。

## 5. 验证

- `npm run build` 通过。
- 浏览器实测：hero 选择框选宠生效、刷新后记住、✕ 收起/小球还原、跨视图常驻、点击有反应、拖动到任意位置并记忆、图鉴为空不渲染。
