## 背景与目标

用户反馈：对战页面缺乏风格化、质感与游戏感，结算页同样朴素；要求参考 GitHub 高星项目的对战 UI 进行复刻，并把参考来源写进 README。

当前状态（1280×900 截图评估）：
- 战斗页已有基础氛围（暗蓝渐变、透视网格、光环、火花粒子），但整体偏「仪表盘/科技感」，打击感与游戏感不足。
- 结算页是一张深色圆角卡片 + ✦ + 数字统计，缺少胜利仪式感。

## 风格方向（用户选定：B 掌机像素风）

参考的高星仓库 / 设计语言：
1. **Shattered Pixel Dungeon**（GitHub ~7k★，Java 像素游戏）— 像素面板、硬边描边框、像素字体的整体质感。
2. **Pokémon Showdown**（GitHub ~9k★，web 对战模拟器）— 对战信息分层：HP 常驻、日志独立滚动、演出与信息不互相遮挡的布局原则。
3. **GBA 世代宝可梦 HP 框设计语言** — 底部/角落常驻 HP 框、分段血条、像素对话框 + ▼ 翻页指示的交互语言。

（另外生成了三张风格概念图做过 A/B/C 对比，用户选定 B：/tmp/gitmon-style/concept_b.jpg。）

## 设计

### 1. 战斗页（battle-arena.css 重写为主 + Battle.jsx 结构微调）

- **掌机屏幕感**：战场 `.battle-field` 加 CRT 扫描线（repeating-linear-gradient 半透明横纹）、屏幕内阴影圆角、轻微暗角；隐喻从「暗蓝科技竞技场」转为「掌机屏幕」。
- **像素描边**：面板改 box-shadow 技法做 2~3px 硬边双线框（深底 + 米白像素框），保留现有金色 `--accent` 作强调色。
- **HP 面板**：浮层卡改为 GBA 式常驻角框——我方左下、敌方右上；HP 条改分段像素格（掉血逐格消失 + 低血闪红）；含 Lv / 品质 / 属性信息。
- **战斗日志**：底部像素对话框（双线边框、等宽像素字体、最新行带 ▼ 指示、打字机逐字出）。
- **招式演出**：回合开始顶部闪「招式横幅」（属性色大字 + 像素粒子）；命中时方形像素颗粒爆裂 + 屏幕震动 + 暴击闪白；伤害数字像素描边弹出。
- **字体**：中文像素字体（woff2 本地打包，不依赖 CDN）。

### 2. 结算页（重做）

- 全屏掌机结算画面：像素五彩纸屑下落、中央像素描边大徽章（胜利金章 / 惜败银章）。
- **S/A/B 评级**：按回合数 + 存活数计算，大号像素字母砸入动画。
- 统计改分段经验条：像素格逐格填充 + 数字滚动；MVP 精灵放大展示在徽章旁。
- 四个按钮改像素按键（按下 2px 下沉位移）。
