# 种族立绘素材规格（给美术/生成用）

游戏里的每只精灵 = **一个种族 × 一到两个属性 × 一个进化阶段**。种族由仓库「是什么类型的东西」决定，属性由主语言决定。把立绘按下面的目录丢进去，代码会自动优先使用它；没放素材的格子继续用 seed 生成的像素精灵，所以可以一张一张慢慢补。

## 一、七个种族（这是你需要生成的对象）

| # | key | 种族 | 对应的仓库 | 判定条件（`detectSpecies`） | 现在的体型 | 建议形象方向 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | `beast` | **兽型** | Web 应用 / 前端框架 | topics 或描述命中 `web / frontend / react / vue / next / svelte / angular`，或根目录有 `index.html` + JS/TS/Vue | `biped` 直立兽 | 圆头大眼、竖耳、四肢着地或半直立的小野兽；活泼、亲和 |
| 2 | `bird` | **鸟型** | 工具 / CLI | 命中 `cli / command-line / terminal / toolkit`，或根目录有 `bin` / `cmd` | `winged` 有翼 | 尖喙、羽冠、折叠翅膀；机敏、轻快、有点狡黠 |
| 3 | `element` | **元素型** | 库 / 框架（默认兜底） | 以上都不命中 | `slime` 团块 | 无固定骨架的团块 / 流体 / 晶体，靠属性色与纹理区分；纯粹、抽象 |
| 4 | `dragon` | **龙型** | AI / 数据 | 命中 `machine-learning / llm / pytorch / tensorflow / nlp / inference`，或语言含 Jupyter Notebook | `quadruped` 四足 | 长颈、背棘、尾巴，体型偏大；有威压感、稀有感 |
| 5 | `flying` | **飞行型** | 移动端 | 命中 `android / ios / mobile / flutter / react-native`，或根目录有 `android` / `.xcodeproj` / `pubspec.yaml` | `winged` 有翼 | 宽翼、流线身体、悬浮姿态；轻盈、现代 |
| 6 | `phantom` | **幻兽型** | 游戏 / 图形 | 命中 `game / graphics / shader / renderer / unity / godot` | `golem` 巨像 | 面具、漂浮部件、发光符文；神秘、非实体 |
| 7 | `fairy` | **精灵型** | 文档 / 博客 | 有 `mkdocs` / `_config.yml` / `docusaurus` / `docsify`，或文档类关键词且仓库 < 400KB | `spirit` 灵体 | 小体型、单眼或大眼、光点环绕；温柔、治愈 |

## 二、九个属性（决定配色，不决定外形）

| key | 属性 | 主色 | 触发语言（占比最高的语言） | 气质 |
| --- | --- | --- | --- | --- |
| `water` | 水 | `#4a9eff` | Python | 柔韧多变、数据之灵 |
| `thunder` | 雷 | `#f5c542` | JavaScript / TypeScript / Vue / Svelte | 敏捷爆发、无处不在 |
| `steel` | 钢 | `#9fb2c8` | Rust | 坚硬极可靠 |
| `earth` | 地 | `#a67c52` | Go | 朴实稳重、并发之力 |
| `rock` | 岩 | `#b08968` | Java / Kotlin / Scala | 厚重耐久、企业级巨兽 |
| `fire` | 火 | `#ff6b4a` | C / C++ / C# | 原始强大、难驾驭 |
| `wind` | 风 | `#7fd4c1` | Swift / Dart | 轻快现代、移动之翼 |
| `grass` | 草 | `#7bc96f` | Ruby / PHP | 优雅治愈 |
| `normal` | 普通 | `#b8b8b8` | Shell / HTML / CSS / 其他 | 平平无奇、潜力未知 |

外形由**种族**定，颜色与纹理由**属性**定。同一个种族换属性应该是「同一只生物换了配色与纹样」，不是重画另一只。

## 三、需要多少张

最小可用集 = **7 种族 × 9 属性 = 63 张**（每格一张通用图，9 个阶段共用）。想要阶段递进就加阶段图 `-s2 … -s9`；**Lv.500 以上是人形态**，所以最划算的是「通用图 + `-s7/-s8/-s9` 三张人形」，63 格共 252 张封顶（全 9 阶则 567 张，一般没必要）。

### 优先级：先做内置对手池里已经出现的 20 格

● = 现在就会用到（36 只内置对手 + 大多数真实仓库），○ = 先留空（自动回落到像素精灵）

| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 兽型 `beast` | ● | ● | ○ | ○ | ● | ○ | ○ | ● | ○ |
| 鸟型 `bird` | ○ | ● | ● | ● | ● | ○ | ○ | ● | ● |
| 元素型 `element` | ● | ○ | ● | ● | ● | ● | ○ | ○ | ● |
| 龙型 `dragon` | ● | ○ | ○ | ○ | ○ | ○ | ○ | ○ | ○ |
| 飞行型 `flying` | ○ | ○ | ○ | ○ | ○ | ○ | ● | ○ | ○ |
| 幻兽型 `phantom` | ○ | ● | ○ | ○ | ○ | ○ | ○ | ○ | ○ |
| 精灵型 `fairy` | ○ | ○ | ○ | ○ | ○ | ○ | ○ | ○ | ● |

建议顺序：`元素型（13 只，兜底最常出现）→ 鸟型 → 兽型 → 龙型 / 飞行型 / 幻兽型 / 精灵型`。

**进度**：✅ **63/63 格全部覆盖**，素材 378 个（2026-11-09 重切后）。七族各 54 张（6 行 × 9 列）**全部满格、无缺口**：

| 种族 | 阶段覆盖 | 备注 |
|---|---|---|
| 元素型 | 通用 + s2～s5 + s7 | 缺 s6（与其余六族阶段编号不同） |
| 兽型 / 鸟型 / 龙型 / 飞行型 / 幻兽型 / 精灵型 | 通用 + s3～s7 全满 | 54/54 |

`s8`（Lv.800 觉醒）/ `s9`（Lv.999 神话）七族都还没有，命中这两个阶段时逐级回落到 `-s7`；不会白图。

**切图脚本**（`scripts/`）：

- `split-bands.py` —— 当前主用。深底 6×9 大图集：先用水平投影谷值 DP 找 **5 条真实行分界**（行高不均，最后一行是人形大立绘），再在每行带内按等分锚定微调 8 条列分界；深底额外做一层「接近底色且与透明区连通」的残留清理。这一版修掉了旧版按画面等分 6 行导致的 **s6/s7 头顶被切断、一格两个精灵、碎片条** 问题。
- `split-sheet.py` —— 间距宽的九宫格 / 单图，整图连通域分组 + 归一化；同时提供抠底与 `clean_tile` 公共函数。
- `split-watershed.py` —— 距离场种子淹没的早期方案（等分网格，会切头），保留作对照，不再用于生产。
- `make-overview.py` —— 由已切好的 54 张拼 6×9 总览图，目检用。
- `art-check.mjs` —— `npm run art:check` 查覆盖矩阵；`scripts/scan-trim.py` 查素材贴边异常。

## 四、单张图规格

| 项 | 要求 |
| --- | --- |
| 格式 | PNG 或 WebP，**背景透明**（不能是白底，也不要有投影/地面） |
| 尺寸 | 512×512 最稳（1024 也行，会被等比缩到卡片大小） |
| 构图 | 正面偏 3/4 视角，主体占画布约 80%，**脚底/底部贴到画布底部约 8% 处**，左右居中 |
| 描边 | 统一描边风格（建议 4–6px 深色描边），所有图一致 |
| 风格 | **二选一，别混**：① 像素风（64/96 网格，硬边无抗锯齿）② 厚涂卡通风（圆润、平涂 + 一层阴影） |
| 光影 | 单侧光（左上或右上），方向统一 |
| 尺寸感知 | 龙型/幻兽型画得大一些，精灵型/元素型小一些，同画布内用主体占比表达体型差 |

### 生成提示词

**逐格可直接复制的完整提示词在 [`ART-PROMPTS.md`](ART-PROMPTS.md)**（7 种族 × 9 属性 × 4 张 = 252 条，含每种族 9 阶形态表、英文/中文两版）。
下面是通用模板，想自己改的时候用。

```
{种族描述}，{属性气质}配色（主色 {主色}），{属性纹样}，可爱的单只怪物
设定图，正面偏 3/4 视角，全身，站在纯透明背景上，无地面无投影，
统一深色描边，平涂加一层阴影，{风格：像素风 / 厚涂卡通风}
```

- 种族描述：从第一节「建议形象方向」里取
- 属性纹样：水=水流纹/鳞片，雷=电弧/闪电纹，钢=金属板/铆钉，地=岩层/裂纹，岩=矿石结晶，火=火焰/余烬，风=气流/羽毛，草=藤蔓/花瓣，普通=简单几何
- 输出后自查：背景是否真透明、脚底位置、主体是否偏小、描边粗细是否和其它图一致

## 五、放进项目

```
src/assets/species/
  beast/thunder.png         ← 通用图（所有阶段共用）
  element/water.png
  element/water-s2.png      ← 阶段图（可选，覆盖通用图）
  element/water-s7.png
  ...
```

### 阶段后缀对照（9 阶，见 README「进化系统」）

| 后缀 | 阶段 | 起始等级 | 形态 |
| --- | --- | --- | --- |
| 无 | 全部 | — | 通用图，没给阶段图时用它 |
| `-s2` | 初生体 | Lv.10 | 兽形 |
| `-s3` | 成长体 | Lv.50 | 兽形 |
| `-s4` | 成熟体 | Lv.100 | 兽形 |
| `-s5` | 强化体 | Lv.200 | 兽形 |
| `-s6` | 完全体 | Lv.300 | 兽形最终阶 |
| `-s7` | **人形态** | **Lv.500** | **人形（必做，500+ 全靠这套）** |
| `-s8` | 人形态·觉醒 | Lv.800 | 人形 + 强化装束 |
| `-s9` | 人形态·神话 | Lv.999 | 人形终形 |

**优先级**：命中当前阶 → 逐级往下降 → 通用图 → 生成的像素精灵。所以只要给了通用图 + `-s7/-s8/-s9`，全等级段都有得看。

- 文件名里的属性必须是上表的 key（`water` / `thunder` / `steel` / `earth` / `rock` / `fire` / `wind` / `grass` / `normal`）
- 目录名必须是种族 key（`beast` / `bird` / `element` / `dragon` / `flying` / `phantom` / `fairy`）
- 保存后 dev server 会热更新，刷新即可看到；`npm run art:check` 查还缺哪些格子

## 六、显示优先级

1. **玩家自己上传的形象**（`src/customSprite.js`，IndexedDB）——玩家永远能覆盖任何素材
2. **种族立绘素材**（本目录）——有 `-s2 … -s9` 就按进化阶段切换，缺哪级用低一级或通用图
3. **seed 生成的像素精灵**（`src/sprite.js`，monstrjs 部件拼装）——兜底，保证任何仓库都有形象
